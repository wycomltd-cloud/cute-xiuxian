## 開始遊玩

- 線上：部署 GitHub Pages 後，從儲存庫的 **Settings → Pages → Visit site** 開啟。
- 離線：下載本專案 ZIP 並解壓，開啟 `index.html`。
- 遊戲是純 HTML、CSS、JavaScript，沒有額外套件或建置步驟。

## 遊戲特色

- 放置修煉、48 小時基礎離線收益、點擊吐納與境界突破。
- 功法、煉丹、煉器、靈寵、洞府、歷練、秘境、道友、論劍、奇遇、圖鑑、成就與輪回。
- 開局與成功輪回後選擇主角性別；男女各十個境界造型。
- 金丹→元嬰、元嬰→化神各三重天劫；化神→煉虛、煉虛→合體各六重；合體→大乘九重。
- 大乘十層後的輪回九重天劫維持原規則；破境天劫的整場機率沿用原突破率、丹藥和失敗保底。
- 首頁小相機可查看當下造型的乾淨完整圖片。

## 存檔

進度儲存在目前瀏覽器的 localStorage，沒有雲端帳號或跨裝置同步。更換網址、裝置或瀏覽器前，可先於「設定與存檔」匯出，再於新位置匯入。不要把個人存檔上傳到公開儲存庫。

## GitHub Pages 部署

1. 建立公開儲存庫，例如 `cute-xiuxian`。
2. 上傳本資料夾的**內容**；讓 `index.html` 位於儲存庫最外層，與 `assets`、`css`、`js` 資料夾同一層。
3. 前往 **Settings → Pages**。
4. **Source** 選 **Deploy from a branch**。
5. **Branch** 選 **main**，資料夾選 **/(root)**，按 **Save**。
6. 等待部署成功後，使用 Pages 畫面提供的網址遊玩與分享。

請先解壓再上傳檔案及資料夾；只上傳 ZIP 不會自動變成可玩的網站。手機上傳多層資料夾較不方便，建議用電腦瀏覽器拖曳上傳。
