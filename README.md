## GitHub Pages 上傳／更新
解壓後，把 index.html、assets、css、js 等檔案與資料夾直接上傳到專案根目錄，覆蓋同名檔案，請勿把外層 cute-xiuxian-v1.7 資料夾一起上傳。
Settings → Pages → Deploy from a branch → main → /(root) → Save。後續上傳更新會重新部署；正在開啟的頁面需重新整理才載入新版。

## 存檔
進度存在目前瀏覽器的localStorage，無帳號、無雲端同步。更新前可在設定中匯出備份；同網址更新保留原存檔，清除網站資料或更換裝置不會自動帶入進度。
