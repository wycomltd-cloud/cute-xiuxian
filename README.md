# 今天也在摸魚修仙 · Cute v1.9

可愛畫風、繁體中文與輕鬆幽默的放置修仙小遊戲。本包為 **v1.9 GitHub 更新包**，包含完整可部署檔案。

## GitHub 更新方式

1. 建議先在遊戲「設定與存檔」匯出自己的進度備份。
2. 解壓縮本包，把 **index.html、assets、css、js 以及說明及授權檔** 直接上傳至 GitHub 專案根目錄，覆蓋同名檔案。根目錄要直接看見 index.html，不要再包一層資料夾。
3. 等待 Actions 的 Pages 部署顯示成功，再重新整理遊戲。
4. 已開著遊戲的玩家須刷新才會使用新版；每個瀏覽器首次載入 v1.9 會顯示更新公告。若仍顯示舊版，可關閉遊戲頁面後重新開啟；不要清除網站資料。

Pages 設定維持 Deploy from a branch → main → /(root)。本包不是已代為上傳 GitHub 的通知，仍需按以上步驟上傳。

## v1.9 更新內容

### 修行節奏

- 閉關由2倍改為1.3倍，保留切換後鎖定兩分鐘。
- 手動吐納每3秒一次，每次5秒當前修為；每日前100次完整，之後一成（0.5秒當前修為）。首頁顯示完整收益剩餘次數。
- 基準整境耗時：煉氣20分鐘、築基24小時、金丹48小時、元嬰96小時、化神120小時、煉虛144小時、合體168小時、大乘192小時、渡劫216小時。
- 基準為初始三品金靈根、閉關1.3倍、初始洞府6%，每層及時突破、一次成功，未計額外加成／獎勵。後期同步維持逐境加長，避免元嬰之後突然變快。
- 小境界成功率、破境失敗保底、3／6／9重天劫及輪回規則保留；離線上限48小時保留。

### 論道

- 全部道友共用每日修為收益次數：前5次完整，6～10次三成，之後只增加好感。
- 每次基礎獎勵為玩家標準修煉速度的10～20分鐘修為；對方每高一個大境界額外10%，最多20%。不再直接依高階NPC速度發獎。
- 同一道友十分鐘冷卻保留；一鍵論道、逐一論道、刷新頁面共用額度。跨日按裝置本地日期重置。

### 修為丹

- 聚氣丹適用煉氣起；凝元丹築基起；玄芝丹金丹起；太一元丹元嬰起；九轉金丹化神起；隱藏混沌一氣丹煉虛起。
- 普通丹提供適用境界整境需求約5%修為，極品約7.5%；高境界服低階丹不放大效果，低於適用境界不能服用。
- 每日所有立即修為丹（含普通／極品）共用次數：前2顆完整，第3～4顆半效，第5顆起一成。限時加速丹、破境丹與其他類丹不計入。
- 丹囊顯示下顆實得修為、當日次數與藥效；全服及首頁一鍵修煉會先提示連續使用的遞減規則。跳字按實際收益顯示。
- 丹毒維持原機制，出售不增加丹毒、不占服丹次數。

### 坊市、出售與回爐

- 丹藥標準價＝（煉製靈石＋材料估值）×1.25；材料依坊市材料品階基準估值，高於四階使用四階估值。
- 丹藥回收維持煉製靈石的60%，向下取整。所有性格、關係及輪回折扣後，買價不得低於回收價1.5倍。
- 裝備標準靈玉價依原品階公式計算，靈石標準價＝標準靈玉價×500。出售維持標準靈玉價60%，向下取整。
- 裝備最低買價取標準靈石價70%與回收折算價1.5倍的較高者。靈玉買價向上取整，避免貨幣換算產生套利。
- 裝備回爐維持原材料50%，不退煉製靈石；嵌入寶石依既有規則返還。
- 同種成品丹每日限購3顆，各攤位與刷新共用。歐皇升階商品按最終物品重新估價。
- 舊版坊市尚未購買的報價會重新生成；已持有物品及貨幣不刪減。

### 靈石、靈玉及活動額度

一階靈寵探索基礎每小時靈石：煉氣300、築基1,000、金丹3,000、元嬰8,000、化神20,000；煉虛40,000、合體70,000、大乘110,000、渡劫160,000。

靈寵一至五階倍率：1、1.4、1.8、2.3、3；性格、技能及財屬性另計。

- 論劍改為每日零時結算一次，青銅／白銀／黃金／白金／鑽石／仙尊分別0／2／4／6／9／12靈玉；可保留最多4筆待領，不補發每一個離線日。
- 原本待領論劍獎勵保留；由舊十分鐘週期升級時不額外產生一筆獎勵。輪回不重置當日結算標記與待領獎勵。
- 奇遇靈石改用較平緩的境界成長表，不再跟隨修為基礎速度指數成長。
- 為防止掃蕩、守關重刷及高頻活動繞過新節奏，奇遇／秘境／派遣的靈石每日共用額度為同境一階靈寵12小時收入；升境沿用已用比例。靈玉每日共用20額度。
- 奇遇／秘境（含掃蕩）／論劍／雙修的修為獎勵，每日共用最多4小時標準修為額度。標準速度依當前境界、層數與固定1.49係數計算，不吃頓悟或短期丹藥加成。
- **上述活動額度不限制掛機修為、靈寵打工、物品出售、一次性成就；論道、修為丹、吐納另有各自規則。** 用完活動修為／貨幣額度仍可遊玩，其他掉落依原規則發放。
- 首頁顯示活動額度；掃蕩預估與實際結算皆顯示扣除額度後的收益。每日額度不因輪回或刷新重置。

## 存檔與既有功能

沿用 localStorage 存檔鍵 cute_xiuxian_v1，無須重開。更新保留現有境界、修為、裝備、材料、丹藥、貨幣、性別及五修選擇。**保留物品數量不代表保留舊版物品效果或售價**：服用與交易皆採v1.9規則。

進度存在當前瀏覽器，沒有帳號或雲端同步。同網址覆蓋更新可以繼續進度；更換網址／瀏覽器／裝置請自行匯出匯入，清除網站資料會失去本機進度。

本版保留男女境界插畫、女主角長髮、五修境界法器、相機乾淨全圖、幽默文案、道侶性別限制、裝備出售回爐與丹藥出售。
