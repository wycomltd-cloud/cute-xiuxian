# 今天也在摸魚修仙 · Cute v1.8.5

可愛畫風、繁體中文與輕鬆幽默的放置修仙小遊戲。

## v1.8.5 更新
首頁插畫增加五修專屬法器，與本世選擇綁定，男女主角皆支援。每修各有十個境界對應設計：
- 劍修：桃木小劍一路到虹光天仙劍，劍身、劍鍔與伴劍隨境界變化。
- 符修：黃紙靈符一路到虹光仙籙，符紙、符印與數量升級。
- 陣修：聚氣小陣一路到虹光周天陣，陣環、陣紋與陣眼改變。
- 丹修：小陶丹爐一路到虹光仙丹爐，爐身、爐煙與丹珠改變。
- 體修：暖身氣環一路到虹光不滅身，護體氣環與靈甲升級。
相機全圖保留法器；隱藏操作後可截圖裁切。沿用既有男女境界美術，不新增柔焦。不影響戰力、養成或存檔。
保留v1.8的本世五修鎖定、論劍剋制、整數奇遇結算，以及先前裝備回爐／出售、丹藥出售、長髮女主角與破境天劫。首次載入新版顯示本次更新公告。

## GitHub Pages 上傳／更新
解壓後，把 index.html、assets、css、js 等檔案與資料夾直接上傳到專案根目錄，覆蓋同名檔案，請勿把外層 cute-xiuxian-v1.8.5 資料夾一起上傳。
Settings → Pages → Deploy from a branch → main → /(root) → Save。後續上傳更新會重新部署；正在開啟的頁面需重新整理才載入新版。

## 存檔
進度存在目前瀏覽器的localStorage，無帳號、無雲端同步。更新前可在設定中匯出備份；同網址更新保留原存檔，清除網站資料或更換裝置不會自動帶入進度。
