## v2.0.3 宗門待辦自動累積

- 宗門事務每2分鐘新增1件；授業每10分鐘新增1次。已有未處理待辦也持續新增，在線／背景／關閉網頁期間皆可累積。
- 以固定時間軸累積數量，不因處理待辦而重啟計時。例如先處理完現有待辦，離線1小時，回來會新增30件事務與6次授業。
- 頁面顯示待處理／待授業數量與下一次新增倒數，首頁提醒也顯示數量。有多份時可連續按；每次處理一件事務或授業一堂，不需每次重等冷卻。
- 單次獎勵、丹毒與職位待遇不變；待辦生成不自動發修為、貨幣或貢獻，必須由玩家按下處理才結算。
- 待辦數量沒有新增每日／48小時封頂，也不因跨日清空。其他掛機收益及俸祿仍沿用原離線上限，未一併修改。
- 刷新、存檔、重新讀檔與多次查詢只按新增時間計算，不重複生成。用數字記錄待辦並逐件展開事件，長離線不建立巨型事件陣列。
- 離宗時保留本世待辦與尚未走完的生成間隔；離宗期間不新增，再入宗才繼續。成功輪回後待辦清空，下一世重新計算。
- 新入宗沿用原本立即可處理1件事務／1堂授業；近期已論道者，第一堂仍等原交接冷卻結束。反覆離宗再入宗不重送初始次數。
- v2.0.2及更早存檔，保留原待決事務、未完成冷卻、既有資產與進度，從最後存檔時間銜接離線累積，不追溯整段角色生涯。

本版增加可處理總次數，先前v2.0.1的兩路成長時間比較屬歷史指定情境，不能視為本版累積待辦玩法的速度保證。散修奇遇與其他系統未在這次一併修改。

- 金丹後未入宗／選散修者：奇遇、論道、鬥法、雙修及鎮妖塔挑戰／掃蕩的活動修為提高25%，成功領取時另累積丹毒。標準化修為越多，當次雜氣越多，每筆0.2～8點，丹毒總值仍沿用0～100。

- 基礎掛機、吐納、金丹前收益、靈石／靈玉收益與普通丹藥藥效不因散修路線加25%。散修活動較高回報，不代表所有情境的總修行速度都必然較快。
- 原丹毒自然衰減、減速與服丹限制保留；修正離線計算，使高丹毒減速只持續到自然衰減至50點為止，不再錯套整段離線時間。沒有加入每日資源收益上限。

## 平衡驗證的範圍

以從金丹一層到大乘十層「具備輪回挑戰資格」為比較終點。v2.0.1每日登入2／6／24次、同等活動步驟的情境，每組20個固定種子，宗門相對散修平均時間差為−4.09%／−2.85%／−1.00%。這是指定情境的結果，並非玩家時間保證；高頻冒險需要管理更多丹毒。新版本不宣稱散修在所有玩法下都必然更快。

情境採相同閉關與25%永久加成；散修論道全體、一次代表性奇遇、3場鬥法；宗門處理1件事務、授業、3場大比，以活動靈石／貢獻買丹並領俸祿。沒有注入免費資產，沒有模擬共同功法裝備、全部奇遇／坊市交易或完整經濟，亦不保證最後九劫成功。細節與結果見 verification/sect-progression-results.json。

## 送禮：不同道友共同累計50次

- 道友固定50位，舊存檔不足會補足，保留原道友與好感關係。
- 每次送出1件未穿戴裝備、丹藥或殘片，成功扣物後全體計數＋1。殘片合計功法袋與通用揹包；鑲嵌寶石隨裝備送出。
- **送給任何道友都算同一個總數**。例如送給甲20次、乙15次、丙15次，全體累計50次便觸發一次回禮。
- 全體第50、100、150……次送禮時，由一位已收過禮且在世的道友立即回禮，不一定是收到第50件禮物的那一位。
- 回禮可能為 **靈石／靈玉／裝備／丹藥／功法殘片**。每滿50次保證一次回禮，種類在可發放的候選中隨機。
- 保留上一版的回禮價值控制：以這50件送禮估值的10%為回禮估值預算，靈石至少1；靈玉每枚按500靈石估值。裝備、丹藥、殘片從當前境界可用、非隱藏且估值不超出預算的品項抽取。低價禮物的一批可能只有部分回禮種類符合預算；不同種類不保證等機率或等價。
- 送禮提高收禮對象好感，每次1～8點，上限100；全體計數與個別好感分開，原道侶條件保留。
- 全體累計數、距下次回禮次數、待領回禮顯示於道友頁。個人詳情同時顯示該位收禮數及全體總數，避免混淆。
- 計數與待領紀錄可存檔，跨日、刷新與輪回不重置。無物品、穿著中的裝備或不存在的禮物不扣物、不計次。

### 舊版送禮紀錄遷移

- 合計所有道友原有 `giftsReceived`，轉成全體總次數。
- 舊版已經發放的每人50次回禮保留為已領紀錄，不會因修正再發一次。
- 合併後若已達全體50次門檻、但舊版因分開計數未發放，會生成待領回禮；道友頁提供「領取待領回禮」，無須額外再送一件。
- 例如甲25次＋乙25次，舊版沒有回禮，更新後可補領1次；甲75次＋乙25次，舊版已發1次，更新後只補缺少的第2次。
- 遷移只執行一次，領取後刷新或讀檔不會重發。
